# Research Repository Frontend

This is the frontend codebase for the Research Repository System

Please read the [documentation](https://r4ppz.github.io/research-repo-docs/) for more info.

---

If you wanna try this running locally or want to contribute.

Make sure you have nodejs and git installed.

```bash
git clone https://github.com/r4ppz/research-repository.git
cd research-repository

# install deps
npm install

# build project
npm run build

# run locally
npm run dev
# or
npm run preview
```
